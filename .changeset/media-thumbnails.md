Media thumbnails show more than a generic icon. In the media library, the media picker and media field previews, a video shows its first frame (loaded only once it scrolls into view, falling back to an icon if it can't play), and a document shows a coloured type badge (PDF, DOC, XLS, PPT, ZIP, TXT, or its file extension).
