Many-to-many reference fields can be reordered in the admin. Each chip in the list has buttons to move it earlier or later, and the list is saved in that order. Before, changing the order meant removing items and adding them back. The buttons are labelled for screen readers and work from the keyboard: focus stays on the moved chip, so it can be moved again. A list saved before the API de-duplicated links shows each item once.
